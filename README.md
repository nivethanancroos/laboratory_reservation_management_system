# Laboratory Reservation Management System

A web-based system built with **PHP**, **MySQL/MariaDB**, and **Bootstrap** to manage laboratory item reservations.

## Features
- Student sign-up & login
- Technical officer login
- Request & manage lab items
- View request history & profiles
- Officers: approve/issue/return items, manage inventory & students

## Tech Stack
- PHP 8.x  
- MySQL / MariaDB  
- Bootstrap 4  

## Setup
1. Install XAMPP / WAMP / LAMP.  
2. Copy `Lab_ms/` to your web server root (`htdocs/` or `/var/www/html/`).  
3. Create a database `lab` and import `lab.sql`.  
4. Start Apache & MySQL, then open:  
   - Student login → `http://localhost/Lab_ms/index.php`  
   - Officer login → `http://localhost/Lab_ms/to_login.php`
